# Rabiya Jamil Portfolio

A responsive static portfolio recreated from the supplied portfolio design.

## Files
- `index.html` — all page content
- `style.css` — responsive design
- `script.js` — mobile menu + small interactions
- `assets/` — images

## Add your real images
Put these files inside `assets/`:
- `profile.jpg` — your real profile photo
- `project-hornnature.jpg` — Horn Nature screenshot
- `project-laravel.jpg` — Laravel project screenshot
- `project-ai.jpg` — AI/RAG project screenshot

The website already has fallbacks if an image is missing.

## Change your links
Open `index.html` and replace:
- `your-email@example.com`
- `https://github.com/`
- project `#` links
- project descriptions/titles as needed

Your LinkedIn is already connected:
https://www.linkedin.com/in/rabia-jamil786/

## Run locally
Simply double-click `index.html`, or use VS Code Live Server.
